
Como pegar um usuario e listar todos os itens relacionados a ele?

http://localhost:1337/api/users/me?populate=* -> Lista tudo que estiver relacionado a aquele usuario

Pegando algo especifico:

http://localhost:1337/api/users/me?populate=pets -> Lista todos os pets daquele usuario




Url base é: http://localhost:1337
